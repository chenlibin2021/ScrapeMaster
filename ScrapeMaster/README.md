# ScrapeMaster

A powerful web scraping tool for various platforms including Xiaohongshu.

## Features
- Multi-platform scraping support
- Browser automation
- Proxy management
- Comment extraction
- Data export capabilities

## Project Structure
- `src/` - Source code
- `docs/` - Documentation
- `scripts/` - Utility scripts
- `config/` - Configuration files
- `data/` - Data files

## Quick Start
1. Install dependencies: `npm install` or `pip install -r requirements.txt`
2. Configure settings in `config/`
3. Run scraping scripts
