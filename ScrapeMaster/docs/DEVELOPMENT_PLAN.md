## 技术决策点

### 架构选择
- ✅ 采用 Scrapy 作为核心框架
- ✅ 借鉴 redbooks 的页面解析逻辑
- ✅ 保留 Playwright 用于复杂交互

### 技术栈
- **框架**: Scrapy
- **浏览器自动化**: Playwright (复杂页面) + Scrapy 原生请求 (简单页面)
- **数据存储**: SQLite + Excel/CSV
- **代理管理**: 集成现有代理系统
- **任务调度**: Scrapy 内置调度器

### 代码组织
```
scrapemaster/
├── spiders/           # 爬虫定义
├── items.py          # 数据结构
├── pipelines.py      # 数据处理管道
├── middlewares.py    # 中间件（代理、User-Agent等）
├── settings.py       # 配置
└── utils/           # 工具函数
```
